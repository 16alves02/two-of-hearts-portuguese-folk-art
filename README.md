# Two of Hearts - Portuguese Folk Art

A vector illustration project inspired by **Lenços de Namorados**, the traditional love handkerchiefs from the Minho region of Portugal.

This project explores the connection between Portuguese cultural heritage, romantic symbolism and contemporary vector illustration.

## Project Overview

The **Two of Hearts (2♥)** represents love, connection and unity.

The front features two stylized birds beneath a central heart, surrounded by floral details inspired by Portuguese embroidery. The back features a continuous decorative pattern that maintains visual consistency with the front.

The color palette combines cream, red, pink, green and blue.

## Cultural Inspiration

Lenços de Namorados are a traditional form of embroidered folk art associated with the Minho region of Portugal. Their hearts, birds, flowers and romantic symbolism inspired the visual direction of this project.

This work explores how Portuguese folk art can be reinterpreted through contemporary graphic design and vector illustration.
